مشروع: مدير المهام البسيط (Simple To-Do CLI)أداة برمجية خفيفة بلغة بايثون تهدف لتنظيم اليوميات عبر واجهة الأوامر.الوظيفة: إضافة وعرض المهام في قائمة مرتبة وتفاعلية.التقنيات: يعتمد على بايثون الأساسية (Basic Python) دون مكتبات، مستخدماً القوائم (Lists) وحلقات التكرار (Loops).الميزة: سرعة الأداء، بساطة الكود، وسهولة التعديل عليه.
